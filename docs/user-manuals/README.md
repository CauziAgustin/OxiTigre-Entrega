## Comportamiento común de las pantallas

- Las grillas no seleccionan el primer registro automáticamente. Primero elegí la fila sobre la que querés trabajar.
- En el filtro elegí **Todas las columnas** o una columna específica y escribí una o varias palabras.
- Las fechas se pueden buscar por día, día/mes o día/mes/año abreviado; por ejemplo `1`, `1/8` o `1/8/26`. También se aceptan ceros iniciales.
- **×** limpia el filtro y **?** muestra la ayuda de la pantalla.
- Verde identifica una acción principal, gris una consulta o navegación, ámbar una acción que exige atención y rojo una cancelación, reversión o acción destructiva.
